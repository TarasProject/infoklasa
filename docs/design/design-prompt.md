# Промпт: дизайн навчального сайту з інформатики

Ти — досвідчений UX/UI-дизайнер освітніх платформ. Створи дизайн навчального сайту з інформатики.

## Контекст

- Автор: вчитель інформатики в ліцеї в Кракові (Польща).
- Аудиторія: учні ліцею (15–19 років), а також усі, хто вчить інформатику.
- Мови: українська, польська, англійська. Перемикач мов завжди видимий і працює без перезавантаження.
- Якщо перекладу матеріалу немає, показується позначка «Переклад відсутній» і доступна версія іншою мовою (без порожніх сторінок).
- Стек: React + Vite, react-i18next. Дизайн має легко переноситися на компоненти.

## Мета сайту

Учень швидко знаходить тему → читає матеріал → одразу перевіряє себе тестом, інтерактивною вправою або завданням до цієї ж теми. Все, що стосується однієї теми, зібране в одному місці.

## Структура сторінок (публічна частина)

1. **Головна**
   - Пошук по центру.
   - Один банер (без слайдера), яким керує адміністратор: картинка або анімація, заголовок, кнопка.
   - Смуга оголошень (напр. «10–17 жовтня — олімпіада»).
   - Швидкий вхід у розділи.
   - «Продовжити з місця, де зупинився» для залогованих.
   - Нові матеріали.
2. **Каталог тем**
   - Групування за класами (1–4 клас ліцею) і розділами (алгоритми, програмування, мережі, бази даних тощо).
   - Фільтри за типом (матеріал / тест / вправа / завдання) і складністю.
   - Мітки складності: базовий / середній / поглиблений.
3. **Сторінка теми**
   - Матеріал: текст, картинки, відео, формули, код.
   - Секції або вкладки: «Тести», «Вправи», «Завдання», «Додаткові матеріали».
   - Хлібні крихти, навігація «попередня / наступна тема».
   - Кнопка «Додати в закладки» (для залогованих).
   - Версія для друку / збереження в PDF.
   - Терміни з глосарію підсвічуються, при наведенні чи натисканні з'являється визначення.
4. **Тест / інтерактивна вправа**: автоматична перевірка, пояснення правильних відповідей, результат.
5. **Підготовка до матури з інформатики**: окремий розділ.
6. **Глосарій термінів**: алфавітний список з пошуком, трьома мовами, з посиланнями на теми.
7. **Результати пошуку**: миттєвий пошук з підказками, відкривається також через Ctrl+K.
8. **Оголошення / новини**.
9. **Зворотний зв'язок**: форма повідомлення вчителю, **доступна тільки залогованим користувачам**. Незалогованим показується пояснення і кнопка входу.
10. **Вхід і профіль учня**
    - Вхід через email (необов'язковий, magic link без пароля).
    - Профіль: прочитані матеріали, пройдені тести, прогрес по темах, закладки.
11. **Про сайт / про автора**.
12. **Політика приватності та cookies**.

## Блоки коду

Інтерактивні блоки коду Python і JavaScript: учень редагує код, натискає «Запустити», результат показується в консолі під кодом. Код виконується в браузері (Python — Pyodide, JS — ізольований iframe).

## Приватність (RODO / GDPR)

Більшість користувачів — неповнолітні, тому потрібно передбачити в дизайні:

- Банер cookies з простим вибором (прийняти / лише необхідні / налаштувати).
- Під час реєстрації: згода на обробку даних і відстеження прогресу, посилання на політику приватності.
- Для учнів до 16 років: крок підтвердження згоди батьків (email батьків).
- Анонімна статистика для незалогованих (Plausible або Umami, без персональних даних).
- У профілі: перегляд своїх даних, відкликання згоди, видалення акаунта.

## Адмін-панель (лише для власника)

- **Дашборд аналітики**: відвідування, унікальні відвідувачі, час на сайті, популярні теми; активність залогованих учнів (хто, коли, скільки часу, які тести) — лише для тих, хто дав згоду; графіки за період.
- **Менеджер контенту**: дерево класів → розділів → тем, drag & drop для порядку, статус «чернетка / опубліковано», версії трьома мовами з позначкою, якого перекладу бракує, мітка складності.
- **Редактор матеріалу**: форматований текст, картинки, відео (файл або посилання YouTube), посилання, формули (LaTeX з попереднім переглядом), блоки коду Python/JS з можливістю запуску.
- **Конструктор тестів**: один/кілька варіантів, введення відповіді, відповідність, впорядкування, заповнення пропусків; бал, пояснення, прив'язка до теми.
- **Глосарій**: додавання термінів трьома мовами, прив'язка до тем.
- **Оголошення**: текст, дати показу (з–по), важливість (колір).
- **Банер на головній**: картинка або анімація, заголовок, кнопка, увімкнути/вимкнути.
- **Скринька зворотного зв'язку**: повідомлення від залогованих учнів з позначками «прочитано / відповів».
- **Користувачі**: список, статус згоди, прогрес.

## Дизайн

- Сучасний, простий, дружній, без перевантаження. Інтуїтивний: користувач не повинен вчитися ним користуватися.
- Приємна спокійна палітра з одним яскравим акцентним кольором. Кожен розділ має свій колір-мітку для швидкої орієнтації.
- Світлий і темний режим (перемикач + автоматично за системою).
- Панель доступності: збільшення шрифту, високий контраст, шрифт для дислексії, збільшені інтервали, вимкнення анімацій. Відповідність WCAG 2.1 AA, повна навігація з клавіатури.
- Mobile-first: учні часто заходять з телефона.
- Типографіка, зручна для довгого читання, і моноширинний шрифт для коду.

## Що я хочу отримати

Працюй поетапно, після кожного етапу чекай на мій фідбек:

1. Дизайн-система: кольори (світла і темна теми), шрифти, кнопки, картки, форми, іконки, мітки розділів і складності.
2. Головна сторінка (десктоп + мобільна версія).
3. Каталог тем і сторінка теми з матеріалом, формулою, запускним блоком коду та глосарієм.
4. Сторінка тесту з результатом.
5. Вхід, згода на обробку даних і профіль учня.
6. Адмін-панель: дашборд, редактор матеріалу, конструктор тестів.

Для кожного екрана коротко поясни логіку розміщення елементів.
