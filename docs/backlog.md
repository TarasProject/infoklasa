# Backlog — що далі, після головної сторінки

Тут лежить усе, що описано в `product-brief.md` і `requirements-*.md`, але свідомо
не входить у поточну роботу (`docs/spec/home-page.md`). Порядок — рекомендований.

1. **Каталог тем і сторінка теми** — справжні матеріали замість зразкових із `content/home.ts` (FR-1).
2. **База даних і вхід вчителя** — Neon + Drizzle + Better Auth, як у `adr-0001-stack-decision.md` (FR-3).
3. **Адмін-панель: матеріали, оголошення, банер** — щоб смуга оголошення й банер керувалися без правки коду (FR-3).
4. **Тести з автоперевіркою** (FR-4).
5. **Вхід учня, профіль, «продовжити з місця, де зупинився»** (FR-6). Перед цим — рішення щодо даних неповнолітніх (NFR-4).
6. **Завдання і прийом робіт, класи, журнал** (FR-5, FR-7, FR-8).
7. **Глосарій, розділ «Матура», новини.**
8. **Запуск коду Python/JS у браузері, формули.**
9. **Зворотний зв'язок, анонімна статистика відвідувань.**
10. **Тести в браузері (Playwright)** — щоб вигляд, клавіатуру й телефон перевіряла команда, а не людина.

Коли проєкт дійде до пунктів 2–6, варто підключити Project Factory командою
`/project-factory:onboard` — вона працює з уже наявним кодом.

## Відкладене з рев'ю коду №1 (`docs/review/01-code-review.md`)

- **Шрифт для дислексії без кирилиці (знахідка 2) — потрібне рішення людини.** Lexend не має
  кириличних літер, тож на `/uk` режим «Шрифт для дислексії» показує системний шрифт. Треба
  обрати шрифт із кирилицею (перевірити вручну, як він виглядає українською) або чесно
  написати в панелі, що режим діє лише для латиниці.
- Пошук: доступність порожнього результату (`aria-expanded`, оголошення для екранних читачів),
  фокус-пастка не лише в полі вводу, видима рамка фокусу в полі (знахідки 9, 10).
- Банер перезапускає анімацію при зміні теми й не перемальовується в режимі без анімації, коли
  змінюється системна тема (знахідка 12).
- Назва матеріалу без жодної мови валить сторінку — потрібен тест на файл контенту (знахідка 14).
- Тест перемикача мов перевіряє мок, а не справжні посилання; немає тестів на `SortViz` без
  анімації (знахідка 16) — разом із тестами в браузері (пункт 10 вище).
- Будь-яка невідома адреса дає 200 «Розділ у розробці» замість 404 (знахідка 17) — вирішити,
  коли з'являться справжні сторінки каталогу.

## Розбіжності у вихідних документах, які треба пам'ятати

- `docs/design/design-prompt.md` називає стек React + Vite; чинне рішення — Next.js (`adr-0001-stack-decision.md`).
- `design-brief.md` і ADR називають Tailwind + shadcn/ui; головна сторінка зроблена на звичайному CSS із токенами з еталона. Tailwind можна додати разом з адмін-панеллю.
